### [EloCampo](https://github.com/felipenlunkes/EloCampo) (2026-2026)

EloCampo is a distributed agricultural marketplace. EloCampo connects rural producers (family farming and urban gardens) directly to consumers, eliminating middlemen from the trade chain. ### [osdev](https://github.com/felipenlunkes/osdev) (2021-currently)

osdev is a project that aims to catalog and gather more information about active open source operating system projects, as well as provide selected material that can help in the development of independent operating system projects. ### [Hexagonix Operating System](https://github.com/hexagonix) (2015-currently)

Hexagonix is a simple and lightweight operating system, Unix-like and entirely developed in x86 Assembly. Hexagonix is composed of a simple monolithic kernel, called Hexagon, a shell, Unix-like utilities developed in Assembly, and libraries for developing other utilities. In addition, it is self-hosting, featuring a port of the fasm assembler (flat assembler), the same one used to build it. It operates in 32-bit protected mode, with FAT16 support, and runs on Pentium III processors or higher, with 32 MB of RAM or more. It can be installed on a physical machine and run natively. The system aims to be simple and fast, based on some concepts of the Unix philosophy, and is licensed under the BSD-3-Clause license, a permissive free software license. At the moment, all project documentation is available in Portuguese and English, while the code comments are in Portuguese. Hexagonix has extensive documentation, covering various features of the system, the language, and the hardware. The documentation can be found at: github.com/hexagonix/Doc. The project also aims to be an educational tool, with well-commented code.

**Skills**: Hardware · x86 Assembly · OSDev

### [Which Medicine](https://github.com/felipenlunkes/whichmedicine) (2024-2024)

Which Medicine is a frontend web application developed to address several problems related to medication use in Brazil, such as difficulty reading and understanding package inserts and adverse reactions arising from the administration of incompatible medications, often during self-medication. Self-medication is a fairly common phenomenon, and a fifth of the population reports self-medicating frequently. However, taking medication without a prescription, combined with the use of incompatible medications, causes numerous hospitalizations and deaths in the country. With this problem in mind, and using technology to improve people's lives, we came up with the idea of developing a web application that makes it easier to search for medications and provides, quickly and conveniently, information about registered medications and side effects when taken together with other medications. Application users can register and log in, compare medications to identify possible drug interactions, list and get more information about all registered medications, and share medications on social media, including Facebook, X, and WhatsApp. They can also suggest the inclusion of new medications. There are also admin users, who can add, remove, or edit medication records, as well as approve or reject user suggestions.

The application's interface was designed with responsiveness in mind, and adapts to various screen sizes.

The challenge was to build a web application using only HTML, CSS, and JavaScript, with Bootstrap being the only framework allowed.

**Skills**: JavaScript · CSS · HTML · Bootstrap

### [PX-DOS](https://github.com/felipenlunkes/PX-DOS-Core) (2013-2015)
